# Research_grant_Python
An investigation of the topics that are awarded MRFF and NHMRC grants in Australia

In this project two datasets were collected from public API's from two major funding organisations in Australia, NHMRC and MRFF.
Two different data gathering methods were used. One being a downloaded dataset and the other was programmatically by connecting to an API.
The data was concatenated, assessed according to quality and tidiness metrics, and missing data identified.
Cleaned the data to solve the issues found in the assessing step.
Updated the data store with the cleaned data.
Produced visualisations on the cleaned data, and answered a brief research question on the dataset.

This project demonstrates a professional data-wrangling process and generation of visualisations on the cleaned data.
